scenarios**. A journey selection or navigation link is preparation, not an

3. Follow **setup → open screen → action → expected result → reset** below. A link

4. Check the result in a separate authenticated request, then in narrow layout and
   with keyboard navigation. Record actual messages, labels, focus, consent and
   stale/error behavior. Screenshots prove only the visible state shown.
5. Reset through normal validated product controls and exact fixture cleanup.
   Refuse changed, protected or in-flight targets. Retain genuine history; never

Inspect before extraction/execution. This bounded read-only ZIP inspection writes
only the verified inner production ZIP into a new scratch directory; it does not
execute downloaded PHP. It rejects unsafe names, links, duplicates, unexpected
inner roots and excessive expansion. A layout/digest change requires the artifact
owner's investigation, not a relaxed check:

```sh
python3 - <<'PY'
import hashlib
import io
from pathlib import Path, PurePosixPath
import stat
import zipfile

def inspect(archive, root=None):
    entries = archive.infolist()
    if len(entries) > 10000 or sum(i.file_size for i in entries) > 128 * 1024 * 1024:
        raise SystemExit('Archive expansion limit exceeded')
    seen = set()
    for item in entries:
        name = item.filename
        parts = PurePosixPath(name).parts
        mode = item.external_attr >> 16
        if (not name or name in seen or name.startswith('/') or '\\' in name
            or ':' in name or any(p in ('', '.', '..') for p in name.rstrip('/').split('/'))
            or item.file_size > 64 * 1024 * 1024
            or stat.S_ISLNK(mode) or item.flag_bits & 1
            or (stat.S_IFMT(mode) not in (0, stat.S_IFREG, stat.S_IFDIR))
            or (root and (not parts or parts[0] != root))):
            raise SystemExit('Unsafe or unexpected ZIP entry')
        seen.add(name)
    return entries

wrapper = Path('runtime-wrapper.zip').read_bytes()

with zipfile.ZipFile(io.BytesIO(wrapper)) as archive:
```
